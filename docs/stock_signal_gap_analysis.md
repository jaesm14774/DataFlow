# 台股訊號缺口盤點（2026-11-28）

目的：列出「已收進來但沒轉成訊號」與「完全沒收」的資料，依「歷史深度、可批次抓取、可用 PIT 驗證」排序。
狀態分類：scored（有研究因子/規則）、context-only（只當卡片背景）、computed-no-reader（有算但沒人讀）、not-collected（沒收）。
原則：新訊號一律先走 research-only 的預先登記因子（`research_signals.FAMILIES`，符號先固定），不動 `signal_rules.py`；
結果以長期動態驗證為準，短期僅供參考；缺值當未知，不補零。

## C. 建議順序

1. （已做）個股基本指標價值因子，立即開始 forward shadow 評分。
2. 累積 ≥ 60 個交易日 PIT 版本後，登記 SBL、處置/注意股、季度獲利因子。
3. 庫藏股事件研究（已有 `庫藏股_歷史`，長歷史）：宣告後 N 日超額報酬。
4. 外資持股比（上市）待使用者決定取得方式。
